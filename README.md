# Dynamic Pricing Optimization and Revenue Intelligence System

AI-powered Dynamic Pricing Optimization and Revenue Intelligence System developed as part of the **Infosys Internship Program**.

---

## 📌 Project Overview

This project is designed to help businesses optimize product pricing using data analytics and Artificial Intelligence. It provides a web-based platform to manage products, store datasets, and prepare for AI-driven price prediction.

## 📊 Dataset

The project uses a product dataset containing:

- Product Name
- Category
- Price
- Stock Quantity

The dataset is imported into the PostgreSQL database through the FastAPI backend.
